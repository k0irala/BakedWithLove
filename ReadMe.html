Baked With Love

ReadMe for graders

Baked With Love is a mobile-first bakery e-commerce web application built with ASP.NET Web Forms (C#, .NET Framework 4.8) and a SQL Server Express LocalDB database.

2. Requirements

  • Windows PC with Visual Studio 2022 and the ASP.NET and web development workload, which includes .NET Framework 4.8, IIS Express and SQL Server Express LocalDB.
  • No other installation or database setup is needed.

3. Setup and running

  1. Unzip the submission. It contains BakedWithLove.sln and the BakedWithLove web site folder.
  2. Double-click BakedWithLove.sln. Alternatively, in Visual Studio choose File → Open → Web Site... and select the BakedWithLove folder.
  3. Press Ctrl + F5 (or F5). IIS Express starts and opens Default.aspx.
  4. The database file App_Data\BakedWithLove.mdf is attached automatically using the AttachDbFilename=|DataDirectory|\BakedWithLove.mdf connection string in Web.config (name: BakeryDB).

Optional - fresh demo data: to rebuild the database from scratch, close Visual Studio and run powershell -ExecutionPolicy Bypass -File Database\RebuildDatabase.ps1. It recreates the .mdf from Database\CreateDatabase.sql.

Optional - refresh sample dates: the sample orders are dated relative to when the database was built, so after a week the dashboard's "Sales - last 7 days" chart is empty. Running Database\RefreshDemoDates.sql against the database moves all sample dates forward so the newest order is a few hours old again (it keeps all other data).

4. E-mail notifications

By default EmailMode = Pickup in Web.config, so order and custom-cake e-mails are saved as .eml files in App_Data\Emails. You can open them in Outlook or Windows Mail. No mail server is needed. The same messages also appear under Notifications on the customer's Profile page.
To send real e-mail, set EmailMode to Smtp and fill in the <smtp> settings in Web.config.

5. Quick walkthrough

  1. Visitor: browse Home, the Menu (search, filter, sort), Ready to Take and product details. Send a comment on the Contact page.
  2. Customer: log in as the customer, add items to the cart and check out. Choose Delivery or Pickup (with a time slot), optionally mark it as a gift, use loyalty points and pick a simulated payment method. Then track the order under My Orders.
  3. Custom cake: fill in the Custom Cake form and optionally upload a reference photo. Accept the admin's quote on the same page.
  4. Admin: log in as admin. Confirm the order under Orders, then move it to Out for Delivery and Delivered. The customer is notified each time and earns loyalty points on delivery.
  5. Admin: manage Products, Categories and pickup slots, Users, Custom cake quotes, and Reviews and feedback. The dashboard shows sales charts and stock alerts.
  6. Customer: once an order is delivered, rate the products from the order page.

6. Folder structure

  • Admin/ - admin-only pages (protected by forms authentication roles in Web.config)
  • Member/ - pages that need a login: cart, checkout, orders, profile, custom cake
  • App_Code/ - shared C# classes: Db (data access), Auth (hashing and login), Shop (business rules), Notify (e-mail), Flash (messages)
  • Controls/ - user controls: ProductCard, OrderTimeline, StarRating
  • App_Data/ - SQL Server database (.mdf) and saved e-mails
  • Database/ - SQL script, rebuild script and sample-date refresh script
  • Images/, Styles/, Scripts/, Uploads/ - media, hand-written CSS, JavaScript, customer uploads
